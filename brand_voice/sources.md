# Brand/editorial voice — Google Docs sources

These are the canonical, live-editable sources for Giusi's brand and editorial
voice. The `generate-workbook` skill fetches them at the start of each run and
snapshots them into `brand_voice/google_docs/` (see that folder's contents and
`brand_voice/README.md` for how the hybrid live+snapshot flow works).

Edit the Google Docs directly to update voice guidance — do not hand-edit the
snapshots in `brand_voice/google_docs/`, they're overwritten on the next run.
